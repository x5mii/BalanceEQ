# BalanceEQ 1.2.1 — development candidate (build 8)

Neutral now refits the published headphone measurement toward the named compatible
reference instead of only adapting a published preset between targets. Custom targets
based on Neutral use the same fitting. Existing saved presets and Harman are unchanged;
reapply Neutral to opt into the new correction. Public 1.2.0 and its update feed remain
unchanged during development.

The open reference curve itself is unchanged. This does not reproduce Sonarworks' own
speaker-to-headphone transfer curve or establish a validated mixing target. The new fit
reduces model-based response error under conservative constraints; it cannot guarantee
flatness of an individual pair or better mix translation.

The existing biquads are refined without adding bands or playback buffering. Fit-input
smoothing and conservative treble handling avoid chasing every narrow measurement dip.
Raw graph residuals remain visible. The old correction is retained if predicted raw
20 Hz–6 kHz error would worsen. Automatic preamp headroom is recalculated after fitting.
New presets record the fitting revision, while older presets keep their saved sound.

Developer ID signing/notarization, physical latency, Intel/macOS 14.2 runtime and full
hardware/audio/VoiceOver acceptance remain separate and unverified.

All 35 tests pass. Harman was explicitly verified to correct the midrange and treble against the compatible target, outperforming a bass-shelf-only EQ. The local candidate passes UI application and persistence checks; user presets were preserved.
