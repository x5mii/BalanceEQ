# BalanceEQ 1.2.1

Released 10 November 2026, build 8, as an ad-hoc-signed, unnotarized community build.

Neutral now refits the published headphone measurement toward the named compatible
reference instead of only adapting a published preset between targets. Custom targets
based on Neutral use the same fitting. Existing saved presets and Harman are unchanged;
reapply Neutral to opt into the new correction. Previous release assets remain available.

The open reference curve itself is unchanged. This does not reproduce Sonarworks' own
speaker-to-headphone transfer curve or establish a validated mixing target. The new fit
reduces model-based response error under conservative constraints; it cannot guarantee
flatness of an individual pair or better mix translation.

The existing biquads are refined without adding bands or playback buffering. Fit-input
smoothing and conservative treble handling avoid chasing every narrow measurement dip.
Raw graph residuals remain visible. The old correction is retained if predicted raw
20 Hz–6 kHz error would worsen. Automatic preamp headroom is recalculated after fitting.
New presets record the fitting revision, while older presets keep their saved sound.

Developer ID signing/notarization, physical latency, Intel/macOS 14.2 runtime and full
hardware/audio/VoiceOver acceptance remain separate and unverified.

All 35 tests pass. Harman was explicitly verified to correct the midrange and treble against the compatible target, outperforming a bass-shelf-only EQ. UI application and persistence checks passed; user presets were preserved.

## Install or update

On 1.1.2 or later, choose **Check for Updates…** in the app's menu-bar menu. The signed
feed advertises 1.2.1/build 8. Updates preserve presets and stop audio during restart;
choose Start EQ afterward. Reapply Neutral to opt into the new measured fit.

For new installations or older versions, quit BalanceEQ and paste:

```sh
/bin/bash -c 'set -e; installer=$(curl -fsSL https://raw.githubusercontent.com/x5mii/BalanceEQ/v1.2.1/scripts/install.sh); /bin/bash -c "$installer" -- --allow-unnotarized'
```

Older install commands also download the latest release. The installer verifies the
checksum and code integrity. This community build has no Apple-verified developer
identity: the explicit option permits installation without disabling Gatekeeper or
removing quarantine. Open `~/Applications/BalanceEQ.app` manually; if macOS blocks it
and you trust the release, use System Settings → Privacy & Security → Open Anyway.
Audio permission can be requested again after an ad-hoc update.

Source is in the `v1.2.1` tag; `BalanceEQ.zip` is universal arm64/x86_64, with its SHA-256
checksum alongside it. Sparkle signatures authenticate the feed and archive; they do
not provide Apple notarization. Signing-key password requests are maintainer-only,
not a requirement for people installing updates.
