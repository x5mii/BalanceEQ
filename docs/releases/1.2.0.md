# BalanceEQ 1.2.0

Released 10 November 2026, build 7, as an unnotarized community build.

Choose your headphones, choose Neutral, Harman or Custom, then Apply Correction.
The main graph compares the predicted result against the chosen target on one
shared Neutral scale. Manual EQ and the live digital spectrum are under Advanced.
Frequency sliders always sort lowest to highest, retaining band identity during edits.

Neutral uses the compatible AutoEq reference without its added preference bass shelf.
Harman uses explicitly compatible upstream mappings; 90 measured profiles have no
compatible Harman mapping and show that limitation. Custom adds editable target
points over Neutral or Harman. Published correction filters remain the seed; at most
six biquads adapt the target. No new audio buffers, runtime dependencies or callback
work were added. Actual headphone variation and residual high-frequency errors remain.

Existing presets load unchanged and retain their sound until Apply. New presets save
the selected target and custom bands. APO export contains the combined filters.
Changing a selection is a preview of the choice; the graph continues to show the
currently applied correction until Apply. Bypass shows the uncorrected prediction.

This remains an ad-hoc-signed, unnotarized community build. Sparkle signatures authenticate updates but do not provide Apple notarization. Developer ID signing/notarization, Intel and macOS 14.2 runtime, clean installation, end-to-end latency and full hardware listening acceptance remain unverified. See [the acceptance record](https://github.com/x5mii/BalanceEQ/blob/v1.2.0/docs/ACCEPTANCE.md).

## Verification

All 32 Swift tests, app gesture/lifecycle checks, callback harness, installer and updater checks passed. Both arm64 and x86_64 built and strict nested code-signature verification passed. Target adaptation checks cover the ten distinct target/mode pairs in the pinned catalog; residual headphone errors are still shown.

Actual UI checks covered target application, staged selection, exact headphone selection, graph dragging, mouse-wheel Q, keyboard edits, custom reset, frequency reordering and custom metadata persistence across relaunch. These UI checks ran with processing stopped; the audio callback and buffering are unchanged. Original presets and tuning were restored after testing.

## Install or update

On BalanceEQ 1.1.2 or later, choose **Check for Updates…** from its menu-bar menu. The signed feed offers 1.2.0/build 7. Updates preserve presets and stop EQ during restart; choose Start EQ afterward.

For a first installation or an older version, quit BalanceEQ and paste:

```sh
/bin/bash -c 'set -e; installer=$(curl -fsSL https://raw.githubusercontent.com/x5mii/BalanceEQ/v1.2.0/scripts/install.sh); /bin/bash -c "$installer" -- --allow-unnotarized'
```

The installer downloads the latest release and verifies its checksum and code integrity. Older install commands also fetch the latest release. The explicit option permits this community build without disabling Gatekeeper or removing quarantine. Open `~/Applications/BalanceEQ.app` manually; if macOS blocks it and you trust the release, use System Settings → Privacy & Security → Open Anyway. Audio permission may be requested again after an ad-hoc update.

Matching source is in the `v1.2.0` tag. The universal download is `BalanceEQ.zip`, with `BalanceEQ.zip.sha256` alongside it. Previous releases remain available.
