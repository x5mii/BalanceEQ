# BalanceEQ 1.1.1

Released 10 November 2026, build 5, as an unnotarized community build. This build is ad-hoc signed, without an Apple-verified developer identity. Previous release assets remain available unchanged.

- EQ editor now has draggable points for the active correction bands. Drag horizontally for frequency and vertically for gain; scroll over a point to adjust Q. Higher Q is narrower, lower Q is wider. Non-gain filters retain frequency and Q editing.
- Custom Target uses the same native controls. Arrow keys adjust frequency/gain; Option-up/down adjusts Q. Scrolling outside points keeps normal window scrolling. Trackpad momentum does not continue adjusting a band.
- Renamed the headphone views to **Target error (0 = match)** and **Headphone + target**, with an explanation beside the graph. The green line in target-error view is always zero; only the blue prediction shows how closely the active correction matches the target. The correction editor and digital live spectrum are separate views.
- Leaving an untouched numeric field no longer rounds its stored value or unintentionally disables automatic headroom.

High-frequency residuals are retained. AutoEq smooths measurements and treats the region above 10 kHz as an average during parametric fitting; this is not a promise of perfectly flat acoustic output. See [AutoEq's explanation](https://github.com/jaakkopasanen/AutoEq/wiki/How-Does-AutoEq-Work%3F).

Validation: 27 existing Swift tests, new native-control self-checks for drag mapping, Q changes and bounds, precision-preserving numeric commits, callback checks, installer checks, and universal build. Actual app checks cover correction and custom-target dragging, wheel-Q changes, keyboard Q adjustment and clear graph labels. Audio DSP and buffering are unchanged. Full hardware and VoiceOver acceptance remain as recorded in [ACCEPTANCE.md](../ACCEPTANCE.md).

Live processing was observed on the FiiO K11 at 48 kHz/128-frame I/O. This is not a measured end-to-end latency result. Intel runtime, macOS 14.2, clean-Mac first launch and the remaining hardware checks are still unverified.

## Install or update

Quit BalanceEQ from its menu-bar icon before updating, then run:

```sh
/bin/bash -c 'set -e; installer=$(curl -fsSL https://raw.githubusercontent.com/x5mii/BalanceEQ/v1.1.1/scripts/install.sh); /bin/bash -c "$installer" -- --allow-unnotarized'
```

The installer downloads the latest universal release, verifies its checksum and code integrity, and preserves presets. Older install commands also follow the latest release. The explicit option permits installation of this unnotarized build; it does not disable Gatekeeper, remove quarantine, or launch a rejected app automatically. Open `~/Applications/BalanceEQ.app` manually. If macOS blocks it and you trust this release, use System Settings → Privacy & Security → Open Anyway. Local ad-hoc updates can trigger System Audio Recording permission again.

Source is available in the `v1.1.1` tag and matching source archive. Release assets are `BalanceEQ.zip` and `BalanceEQ.zip.sha256`.
