# BalanceEQ 1.1.0

Released 10 November 2026, build 4, as an unnotarized community build. The previous v1.0.0 assets remain available unchanged. This build is ad-hoc signed, not notarized; clean-Mac and outstanding hardware acceptance remain unverified.

## Changes

- Fix decimal-comma APO imports, including the supplied Beyerdynamic T5 3rd file. Plain LS/HS shelves with explicit Q now import exactly like LSC/HSC. Parsing remains atomic, with line-numbered errors and visible import confirmation.
- Choose among 4,520 offline measured headphone profiles and apply the matching published correction. Existing OPRA profiles remain available separately as EQ-only tunings.
- View the published response before correction, the predicted result using the active DSP coefficients, and the actual paired target. Difference-from-target mode uses a zero reference without hiding residual error. Global preamp attenuation is excluded from this tonal comparison.
- Build custom targets with draggable bell and shelf bands; exact numeric editing, reference/custom switching, reset, automatic headroom and manual preamp remain available. No new audio framework, convolution or playback queue.
- Save calibration references and custom bands in presets; older presets remain compatible. APO export contains the effective filters but cannot preserve the calibration editor metadata.

Target names identify the upstream published result. A headphone name alone is never treated as proof of a Harman version, measurement rig or matching acoustic response. The graph predicts a model’s response; it does not measure your particular pair. Custom Target is independent parametric shaping, not Sonarworks’ proprietary Flat target.

## Validation

All 27 Swift tests, app self-checks, callback and installer checks passed. Both architecture slices built, and live FiiO K11 processing was checked at 48 kHz/128-frame I/O. See [the acceptance record](../ACCEPTANCE.md) for observed results and unfinished hardware/accessibility checks. The source generator pins AutoEq data and records omitted pairs. Licenses and attribution ship in the app.

## Local build

```sh
./scripts/check.sh
./scripts/build-app.sh
```

## Install or update

Quit BalanceEQ from its menu-bar icon before updating, then run:

```sh
/bin/bash -c 'set -e; installer=$(curl -fsSL https://raw.githubusercontent.com/x5mii/BalanceEQ/v1.1.0/scripts/install.sh); /bin/bash -c "$installer" -- --allow-unnotarized'
```

The installer downloads the latest universal release, verifies its checksum and code integrity, and preserves presets. Existing commands using the v1.0.0 installer also follow the latest release. This build has no Apple-verified developer identity. The explicit option allows installation but does not disable Gatekeeper, remove quarantine, or automatically launch an app that Gatekeeper rejects. Open `~/Applications/BalanceEQ.app` manually after installation.

Source for this release is included in the `v1.1.0` tag and the matching source archive. The universal binary is `BalanceEQ.zip`; `BalanceEQ.zip.sha256` contains its SHA-256 checksum.
