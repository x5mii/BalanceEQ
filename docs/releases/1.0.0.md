# BalanceEQ 1.0.0

**Unnotarized community release.** Version 1.0.0/build 3 is a universal, ad-hoc signed download without an Apple-verified developer identity or notarization. The maintainer chose to release it now. Clean-Mac installation and the outstanding hardware checks in [the acceptance record](https://github.com/x5mii/BalanceEQ/blob/main/docs/ACCEPTANCE.md) remain unverified; publication does not establish those results.

BalanceEQ is a free native macOS menu-bar equalizer for one normal stereo output. No accounts, ads, subscriptions, telemetry, or installed audio driver.

## Included

- Up to 32 parametric filters, preamp, smooth bypass, and a response graph calculated from the playback coefficients.
- Offline search across 12,588 headphone profiles, with attribution, and strict Equalizer APO parametric import/export.
- Reliable decimal editing: Q accepts `0.2` or `0,2`; all numeric fields apply on Return or focus change. Escape cancels. Invalid values retain the current tuning.
- An optional live before/after spectrum from actual input and final DSP output. Stereo power is averaged without phase cancellation. FFT work runs outside the audio callback and pauses while hidden or viewing the calculated response.
- Smooth native Core Animation curves, a larger graph and unified band panel, with native slider tracking and double-click reset. Live analysis refreshes at 20 Hz only while visible, with display-only interpolation and reduced-motion support; metering updates stay isolated from the editor.
- Native Apple-blue controls, Liquid Glass on the main action on macOS 26+, and opaque graph/editor surfaces. Earlier systems and reduced transparency use a standard button.
- Menu-bar operation, preserved presets, and Discord stable desktop playback excluded from EQ to retain its audio identity during screen sharing. Participant confirmation of the Discord fix remains pending.

## Reading the graphs

The EQ response is gain in dB; the live spectrum is digital signal level in dBFS, using 2,048-sample Hann-windowed FFTs. The analyzer is a periodically sampled display, not an added playback buffer or a measurement of latency. Frequency resolution depends on sample rate (23.44 Hz at 48 kHz); narrow low-frequency features cannot be resolved precisely. Window leakage and the music itself affect the visible spectrum.

A Harman-target correction profile is not a measured headphone response. The catalog provides filter settings, not raw acoustic measurements and matched target curves. Neither graph verifies that a headphone physically matches Harman. Such a comparison needs compatible acoustic measurement data, target version, measurement rig, and normalization. BalanceEQ does not fabricate that overlay.

## Compatibility and remaining acceptance

- Universal arm64/x86_64 build; minimum macOS 14.2. Intel and macOS 14.2 execution remain unverified.
- One physical stereo float output at a time; separately routed audio and alerts are outside scope.
- Bluetooth recovery, sustained playback, volume/mute behavior across devices, protected media, accessibility acceptance, forced termination during playback, and measured added latency still require the documented checks.
- Local ad-hoc builds may prompt for audio permission again after replacement. The signed release must keep its signing identity and bundle identifier stable.

## Install

Paste into Terminal (macOS 14.2+, no sudo):

```sh
/bin/bash -c 'set -e; installer=$(curl -fsSL https://raw.githubusercontent.com/x5mii/BalanceEQ/v1.0.0/scripts/install.sh); /bin/bash -c "$installer" -- --allow-unnotarized'
```

The installer checks the download checksum, app identity and code integrity, and preserves presets. The explicit option allows installation if Gatekeeper does not approve this unnotarized build; it does not disable Gatekeeper, remove quarantine, or launch the rejected app. Checksums and ad-hoc signatures do not authenticate the developer or replace notarization.

Open `~/Applications/BalanceEQ.app` in Finder after installation. If macOS blocks it and you trust this release, use **System Settings → Privacy & Security → Open Anyway**, following [Apple’s instructions](https://support.apple.com/en-us/102445). Managed Macs may prevent this. Choose **Start EQ** and grant System Audio Recording access when asked. Quit the app from its menu-bar icon before updating.

Alternatively, download **BalanceEQ.zip**, unzip it, and move BalanceEQ.app to your Applications folder. **BalanceEQ.zip.sha256** contains its checksum. Source is available at this release’s tag. The app contains the GPL license and third-party notices.

## Verification

All 22 Swift tests, app self-checks, callback checks, and universal compilation passed for this app. The installer additionally checks unnotarized first installs/updates, refusal without the explicit option, integrity failures, and rollback using isolated fixtures. Actual clean-Mac acceptance, Intel/macOS 14.2 execution, and the device matrix remain pending. Developer ID signing and notarization are planned for a future release.
